💊 Smart Medicine Reminder System

A simple yet effective system to remind users to take their medication on time using both visual (LED, LCD) and audible (buzzer) cues.

🔧 Hardware Components
- Arduino Nano – Main controller
- RTC Module (Real-Time Clock) – Keeps track of time accurately
- 16x2 LCD – Displays time and alert messages
- Buzzer – Provides audible alert
- LED – Visual alert indicator
- Push Buttons – Used to acknowledge and reset the alert

📲 How It Works
1. RTC continuously tracks the current time.
2. At preset medication times, the system:
   - Activates buzzer and LED
   - Displays reminder message on LCD
3. The user presses a push button to acknowledge the reminder.
4. System resets and waits for the next scheduled time.

✅ Features
- Real-time medication reminders
- Visual + audible alerts for better visibility
- Manual setting of time via push button
- Simple and reliable design using basic components

🧠 Purpose
To support individuals, especially the elderly or patients, in taking their medication regularly and on time.
